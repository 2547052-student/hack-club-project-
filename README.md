Monster Clicker Game 

About the Game
Monster Clicker is a simple clicking game 
made using JavaScript and the p5.js library. 
It features two characters: a friendly ghost
and an enemy.
Clicking the ghost increases your score,
while clicking the enemy decreases it.
The aim is to get the highest score possible within 30 seconds.

How I Made It
I created the game using the p5.js Web Editor and JavaScript.
I used random positioning to make the characters appear in different places,
added a scoring system and a 30-second timer, and included start, game-over and retry screens.

How to Play
1. Open the game in your browser.
2. Click anywhere to start.
3. Click the ghost to gain points.
4. Avoid the enemy, as it takes away points.
5. Try to get the highest score before the timer runs out.
6. Click again to play another round.

Tools Used
- JavaScript
- p5.js Web Editor
